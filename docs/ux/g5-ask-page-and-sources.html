Why this is a decision

C8 put Ask behind the palette rather than the panel it recommended, and Lorenzo's amendment reopens exactly the two things a bare palette answer cannot do on its own: an answer that outgrows the overlay needs somewhere to go, and a source that is only ever a name in a list is evidence nobody can actually check. Both questions share one constraint. Ask never writes to canon, so nothing about this page is a proposal, but the sources are still the only thing standing between a plausible paragraph and a checked one, and a design that makes checking one costly is a design that guarantees most of them never get checked.

Guardrail 3 every proposal shows its evidence, never a bare confidence score. Ask is not a proposal, but C8 already ties this guardrail to it anyway: "the same rule is what stands between sources listed and a plausible-sounding answer with nothing under it." This page decides what happens after the source is listed, when a hand actually reaches for one.

Decided

A, amended, taken on 2026-08-13

Decided A rather than the C recommended below, but only for the page: expand in place stands, the same single expanding route A drew, not C's five-question workspace. The source click does not stand as A drew it either. No popover preview and no navigation away: clicking a source opens a side panel holding that entry, with the answer still readable beside it. That is A for the page, and C's "opens beside, stays visible" instinct for the click, without adopting C's multi-question layout around it.

What it settles: the answer route is a single expanding page, not a saved log and not a workspace of several questions, and a source is something a GM opens next to what they were reading, never something that replaces it or previews it in a floating popover. What it costs: #53's answer route now needs a real two-pane layout rather than a single column that only ever fit the answer, and #60's source card needs a target that opens a panel, not a link that navigates away and not a popover that floats over the text.

The answer this page draws throughout

One real question, asked inside Sword Coast (ours), the derived universe from the fixture, because a derived answer is the harder case: one source is the GM's own canon, the other is the pre-indexed Forgotten Realms corpus underneath it, and SPEC 7 requires attribution and a licence link on that second one, on every answer it appears in, not just the first.

Options

Each option answers both halves at once: what the dedicated page actually is, and what happens when a hand lands on one of the two source cards above.

A

Expand in place, sources preview

"Expand this answer" grows the same streamed answer onto its own route. Nothing is saved; leaving the page loses it exactly like closing the palette would. A source click opens a C5-style popover, not a navigation.

Buys

  • Cheapest of the three to build: it is C8's own rejected Full Page option, only reached on purpose instead of by default.
  • A source check costs nothing, exactly the C5 popover pattern already decided and already wired for keyboard and touch.
  • Nothing new to explain: the page looks like the palette's answer, just with room to breathe.

Costs

  • Gone the moment the tab or the route changes; a GM who wants to compare two questions from earlier in the session has nothing to come back to.
  • The query_lore API already accepts up to five questions in parallel and this shape only ever shows one, so a real backend capability sits unused.
  • A popover peek is not quite what "clicking a source goes to that entry" says; a second click inside it is required to actually get there.
B

A saved Ask log, sources navigate

Every question asked, from the palette or the page, is appended to a real, per-universe history the GM can reopen later. Because the answer is never actually lost, a source click can safely navigate straight to the entry.

Buys

  • "Lose the answer" stops being a real cost: the log is where it lives now, one click back from anywhere, so a full navigation to a source is cheap rather than risky.
  • Real product value past a single question: "what did I ask last session about the Ashen Ledger" becomes answerable instead of forgotten the moment the palette closes.
  • A natural home for follow-up depth C8 already worried a narrow panel could not hold.

Costs

  • New persisted state with real questions attached to it: retention, deletion and whether it is GM-only (it has to be, nothing here touches players) all need answers this page did not ask for.
  • Heaviest to build of the three; a chat-shaped history is a bigger surface than "expand" or "one more card" from the other two options.
  • A GM asking one throwaway question ("what's this place called") now writes a permanent-feeling row into a log for something they will never look at again.
C

A five-question workspace, sources open beside

Up to five question cards side by side, matching query_lore's own one-to-five limit exactly. A source click opens the entry in an adjacent pane; the workspace stays visible next to it.

Buys

  • The one shape whose layout matches a real backend limit instead of inventing its own: five parallel questions is what the API already promises.
  • Matches how a GM actually preps: several questions collected before a session, same instinct D6 already relies on for import matching, answered together instead of one at a time.
  • A source click costs nothing: the entry sits right beside the question that cited it, never replacing it.

Costs

  • Heaviest UI of the three for the common one-off question, the same critique C8 made of its own full-page option before Lorenzo's amendment gave it a reason to exist.
  • A three-pane layout (workspace, beside entry, plus whatever B1's own aside column wants) needs real width; narrow screens have to collapse something.
  • Not persisted by default, so it inherits option A's "gone when you leave" problem unless a save action is added on top.

Rejected outright

A source list collapsed to an info icon

Cramped space is a real cost, C8 already named it against the palette, and shrinking every source card to a small "i" with a tooltip is the tempting fix: one glyph instead of a badge, a name and a licence line. It is Guardrail 3 failing quietly: a tooltip with no quote and no link is a source that cannot actually be checked, only pointed at, and it directly breaks SPEC 7's requirement that a derived answer carry attribution and a licence link on every answer it appears in. Cramped stays a real constraint on the palette; the fix is a bigger surface to move into, which is this page's entire premise, not a smaller card.

What I would take

C, the five-question workspace, with A's cheap start

Take C. The API this page is a window onto already does five questions at once; a shape that only ever holds one is answering a smaller question than the product actually supports, and a GM prepping for a session genuinely does collect several questions before running any of them, the same instinct D6 already banks on. Pair it with B's source instinct in one specific way: within a session the workspace's cards should not vanish just because a source was opened beside them, so "lose the answer" never becomes a real complaint even without a full saved history. A permanent per-universe log is real value but real cost; it earns its place once usage shows GMs actually returning to old questions, not before.

Cheapest way to find out this is wrong: ship the workspace capped at one card, visually identical to option A, and count how often a GM adds a second question in the same session before building the beside-pane and the multi-card layout. If nobody ever reaches for a second question, the workspace was never earning its keep and A was the honest answer all along.

What this locks in

  • #53 Ask's shipped unit is the question card drawn above (askbox, level row, answer, sources, follow-ups), reused up to five times on this page rather than redesigned per surface; the palette and the page render the same component, not two.
  • #60 the derived-corpus card's minimum bar gains a second test: it has to survive being one of several cards on a wide page without the licence line truncating, and the entry opened beside it has to be the real entry, not a stripped preview of it.
  • Deferred: whether a question asked from inside table mode lands in this same workspace or its own quick lookup is out of scope here; table mode's Ask entry point is a separate surface this page does not touch.
