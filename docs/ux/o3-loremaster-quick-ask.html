Why this is a decision

Ask has three doors today and all three leave the page. Sidebar.svelte:104-116 prints a permanent nav row straight to /w/<slug>/ask, with the shortcut printed beside it. CommandPalette.svelte:153-161 turns a question-shaped query into a row that also navigates to /w/<slug>/ask?q=..., and :134-138 sends the shortcut there directly without even opening the palette first. That shortcut, keys.ts:41-51, is mod+shift+A, global, rendered per platform, and nobody reaches for a key combination they have never seen used. On the other end, ask/+page.svelte:176-188 reads the ?q= param once and throws it away with replaceState, and ask/+server.ts:42-87 streams the answer over SSE as sources, tokens, proposals and done, writing none of it anywhere. There is no ask, answer or conversation table anywhere in packages/db/src/schema. So the dedicated page is a one-shot composer wearing a URL, and every one of its three doors costs the entry the GM was actually reading.

Ask never writes to canon, so nothing here is a proposal in C6's sense. But A3 = C already put one box in charge of routing a typed question, and G5 = A already decided what the answer looks like once it expands. Whatever this page adds has to survive both without becoming a second thing to keep in sync, and the moment any option lets the copilot remember a question past the tab closing, it drags a retention answer and a guardrail 5 sentence behind it that this page can name but cannot settle alone.

Guardrail 3 every proposal shows its evidence, never a bare confidence score. Ask is not a proposal, but C8 and G5 already tie this guardrail to it anyway: an answer with nowhere to check its sources is a plausible paragraph with nothing under it. Wherever the answer renders, on a page or in a corner of one, the sources ride along as something a hand can actually open.

Options

A

A floating pill that expands in place

Bottom right, one line when idle carrying the name and the shortcut. A real transform-and-opacity transition grows it into a composer that carries the page's own context, streams an answer with its sources as chips, and offers exactly two exits: open it on the dedicated page, or keep it.

Buys

  • The question gets asked where it occurs and the entry stays on screen behind it.
  • One affordance on every route, which the shortcut never was: nobody discovers mod+shift+A on their own, and the pill is the discovery mechanism the shortcut needed.
  • The animation itself teaches the feature; there is nothing to read first.

Costs

  • A second composer beside the palette's one box, so A3 = C now has a sibling, and the two can drift apart if only one gets maintained.
  • The corner belongs to E3's dock in table mode and to E4's tabs on the phone, so it has to yield in two places rather than one.
  • "Keep" is a new table, a retention policy, and a sentence about what leaves for a provider, guardrail 5, that nothing today answers.
B

The pill only opens the palette

A small button, a mouse affordance for a keyboard feature and nothing more. It opens the existing palette, centred, and a typed question routes to Ask exactly as it does today.

Buys

  • No new surface: A3 = C stays literally true, one input to maintain, and on the phone it is already built.
  • One afternoon of work: a button that opens a palette that already exists.
  • Nothing to keep in sync with the palette, because it is the palette.

Costs

  • Still navigates away from the entry, which was the actual complaint, not the shortcut's visibility.
  • No context chip: a centred overlay is not attached to anything, so "about Aldric Vane" has nowhere to sit.
  • Nothing is remembered, so the dedicated page stays a blank composer, never a history, no matter how many times it is opened.
C

A docked Loremaster bar

A one-line bar at the bottom of the content column, always visible, on every page. It expands upward into a drawer holding the last exchange for this world, a context chip, and a link to the history.

Buys

  • Discoverability is free: the bar is never hidden behind a shortcut or a click to find it.
  • A short conversation survives navigation, which none of the other options manage without a click first.
  • One home for the copilot on every surface, always the same place.

Costs

  • A permanent vertical tax on the reading room the whole design exists to protect, on every page, asked for or not.
  • A head-on collision with E3's dock and E4's tabs, not a yield: two things claim the same line at once.
  • A persistent rail is the "chat with your world" product this one is deliberately not, and it invites treating generated text as canon, the pressure guardrails 1 and 2 exist to resist.

Rejected outright

A floating composer that writes straight into the entry

The corner sits right next to the prose, so letting "keep" write the answer as a new paragraph instead of a row in a history looks like it saves a step. It is Guardrail 1 broken outright: the spec names exactly one exception, a field a re-import writes because the source changed and the user never touched it, and an Ask answer is not that. Whatever the panel drafts stays a draft until a human opens it and accepts it themselves, the same as every other proposal, and being close to the text it might describe does not earn it a shortcut past that.

A bubble that opens itself with an observation

"I noticed Aldric contradicts the Sable Winter" would be a genuinely useful thing to say, and it is exactly what C2 = A already ruled out: proposals arrive quietly, in an inbox, never a modal, and G8 keeps that inbox silent in table mode on purpose so nothing interrupts a session already running. A pill that speaks without being asked is that modal again, just rounder. If the observation is worth surfacing, it is a proposal like any other and it waits in the inbox for the GM to come find it.

What I would take

A, amended so it is not a second box

Take A, but change what it is built from. The pill mounts the palette's own input in a docked placement, so there is one input implementation with two positions rather than two composers to keep in sync, which is what lets A survive A3 = C instead of contradicting it. In table mode it gets out of the way entirely, since E3's two-tier dock already owns that corner and the answer belongs in whatever lane the dock gives it, not floating over it. On the phone it becomes a tab in the bar E4 = A and I10 = B already ship, not a circle drawn over the content, so it never has a corner to lose in the first place.

"Keep this answer" stays the only write, and that is the whole reason the dedicated page can honestly be called a history rather than a chat transcript. Everything typed and abandoned is exactly that, abandoned, the same as closing the palette does today. A log of everything anybody typed is a transcript nobody asked this product to keep; a list of the answers somebody chose to keep is a record.

Cheapest way to find out this is wrong: instrument how many quick asks end in "keep" against how many end in "open in Ask". If almost everything gets expanded onto the page anyway, the quick panel is only a slower door to the same route, and B would have been enough on its own.

As decided

Added after the pick on 2026-08-19, because two of the amendments are visual and a paragraph is a worse specification than a drawing. The mocks above keep the violet and the text button they were proposed with, since that is what the option actually was. This is what gets built.

  • Colour. The pill, the panel, the context chip and the input wear --panel, --line, --ink and --accent, in both palettes per G1. C1 is not repealed: violet stays reserved for AI text nobody has accepted, so the answer inside the panel keeps its marking and its margin note. What loses the violet is the chrome, which was never AI text.
  • The cost of that, accepted. The launcher no longer says "copilot" by colour, so the name and the glyph carry it alone. Anybody tempted to paint it violet again reads this line first.
  • Close. A glyph, not the word, with the accessible name moved to aria-label rather than dropped. It is the one control in the panel a reader never needed a label for, and it was competing with the answer for attention.

What this locks in

  • #285 and #282: the epic and this issue both assume Ask gets a second entry point beyond the sidebar and the palette; whichever option ships, it is the shape both issues build against.
  • The persistence question needs its own issue and a retention answer before the word "history" appears in any label. Nothing in packages/db/src/schema holds a question today, and this page cannot invent that answer on its own.
  • The palette component, #149, grows a docked placement as a real requirement; O3 does not get built by copying its input into a brand-new component that then has to be kept in step with it by hand.
  • The sidebar item at Sidebar.svelte:104-116 stops being "Ask the Loremaster" and becomes the way to the history: once an answer can be kept, the row that used to open a blank composer opens a list of what was actually kept.
  • Nothing about the proposal loop changes. An answer the copilot streams is still not canon until something is accepted, Guardrail 1, whichever surface it streamed onto.
